
Quran Garden — PeerJS Real-time Multiplayer Integration Steps
==============================================================

WHAT YOU HAVE NOW
-----------------
- PeerJS CDN loaded (unpkg peerjs@1.5.4)
- window.MPNet helper: createRoom / joinRoom / send / on / destroy
- Multiplayer Quiz UI wired:
  CREATE ROOM → online room code (Peer id: qg-mp-XXXXXX)
  JOIN ROOM   → connect to host with that code

HOW IT WORKS
------------
1. Host taps CREATE ROOM
   - PeerJS registers id = "qg-mp-" + ROOMCODE
   - Host shares 6-letter code with friends

2. Friend taps JOIN ROOM, enters code
   - New Peer connects to host id "qg-mp-CODE"
   - DataConnection opens → join event

3. Host taps START MATCH
   - Host sends { type: "mp-start" } to all peers
   - Clients can start same match

REQUIREMENTS
------------
- HTTPS or localhost (PeerJS needs secure context except localhost)
- Internet at least for signaling (PeerJS cloud broker)
- After connected, game data can go P2P

TEST STEPS
----------
1. Phone A + Phone B same WiFi/internet
2. Open app on both (https or http://127.0.0.1 via LAN IP)
3. A: Multiplayer Quiz → CREATE ROOM → copy code
4. B: JOIN ROOM → paste code → OK
5. A: START MATCH
6. Check console for [MPNet] logs

NEXT UPGRADES (optional)
------------------------
- Sync each answer: MPNet.send({ type:"mp-answer", pick, score, name })
- Host is source of truth for question index + timer
- Show live peer count from MPNet.peers()
- Private PeerServer if PeerJS cloud is blocked

OWN PEER SERVER (optional)
--------------------------
npm i -g peer
peer --port 9000

Then in ensurePeer:
  new Peer(id, { host: "YOUR_IP", port: 9000, path: "/" })

TROUBLESHOOT
------------
- "PeerJS not loaded" → internet blocked / CDN fail
- Join timeout → wrong code / host closed / firewall
- file:// open → use local server (python -m http.server)
